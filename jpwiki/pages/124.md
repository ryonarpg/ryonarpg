## 枪

### 解说

|  | 蓄力速度 | 伤害修正 | HIT | 射程 | CH | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 普通攻击 | 2 | 100% | 1 | 前2 | 10% |  |
| 蓄力：一文字突き |  |  |  | 前3 | 10% |  |
| 蓄力2：大車輪 |  |  |  | 周2 | 10% | 武器等级7以上 |

长柄前端带刃的武器。长矛与骑枪之间没有特别区分。
蓄力攻击的射程在近战武器中偏长。
不过，完全无法进行错开轴线的攻击，因此很难打中特别敏捷的敌人。
