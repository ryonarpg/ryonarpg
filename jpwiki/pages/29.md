# 角色追加

> 原文：[キャラ追加](https://w.atwiki.jp/ryonarpgb/pages/29.html) ｜ 译自 RyonaRPG 勝手にwiki

与角色相关设定的汇总。
追加或修改角色时请参考使用。

### RPG Maker（RPG Maker）侧

- 特殊技能（天赋）

```
在与要制作的角色 ID（角色列表中左侧显示的数字）相同的 ID 上，只填入天赋名称与说明，
基本上取消「可使用场合」的勾选。
种类选哪个都可以，但没必要特意与其他角色不同，用「开关」即可。
天赋的实装需要单独处理，这个以后再说。
```

- [道具](./161.md)

```
设定装备可否。以战士/魔法/魔法战士/僧侣等角色类型为基础，
仿照现有角色勾选。
不必完全一致，也可以优先考虑该角色的特性。
另外，若角色有专用装备也要设定。（关于装备的新建，此处从略）
```

```
魔法可否也在这里设定。
仿照以下角色的可否勾选会比较方便。
　蒂娜・莉迪亚：擅长魔法。可使用全部魔法。
　塞莉丝・爱莉　：较擅长魔法。可使用大部分魔法。
　诺艾尔・伊兹娜　：魔法中等。可使用到中等程度的魔法。
　莉丝・莱莎：魔法略差。可使用到简单魔法为止。
　女战士・多拉子　：不擅长魔法。大部分魔法都无法使用。
详情记载于 [+txt 仕様] 内的 [魔法制限.csv] 中。
```

- 角色设定

```
姓名、称号、初始装备、头像（如有）、能力值成长曲线、特殊技能
```


- 0512：装备数据获取

```
擅长武器的设定
	在事件接近结尾处，若角色装备的武器属于其擅长类型，则将开关0815：擅长武器设为 ON。
```

- 0202：魅力角色补正

```
角色的初始「魅力」、「ロリ度」、「婊子度」、「サ度」相对基准值 0 上下调整多少。
```

- 0290：三围确定

```
设定变量0501：胸围
变量0502：腰围
变量0503：臀围
变量0504：身高。
若官方已设定这些数值则很简单，未特别决定时则按印象随机。
```

- 0462：变身为捕获角色

```
从上到下依次设定黄金化（3 项）、机器人化（2 项）、通用（1 项），共 6 项。
黄金化是变成黄金像时的图像，机器人化是被改造成机器人后遭废弃时的图像，
通用是在迷宫内倒下时的图像。
另有被催眠期间作为女服务员工作的图像，这一项在地图事件侧设定。
```

### MAP 相关

- MAP0001：Opening

```
复制现有角色的图像事件及其左侧的事件。
角色从上到下依次排列为战士、魔法战士、魔法、其他，因此粘贴到对应的行。
更改图像事件的图像。
第 2 页的出现条件设为「角色ID + 1190」号开关，图像则追加到 CharSet 文件夹的 ash.png 中使用。
另一个事件也要修正文章、开关、变量等，直到第 1～3 页。
EV0003(018,014) 的第 2 页也要仿照现有设定进行语音设定。
ほこグラ旁的 OK 标记表示立绘是否已实装
```

- MAP0362～0370：[蜂袭村](./37.md) 及其下级地图

```
在蜂袭村中，被转生为蜂娘的角色会作为敌人出现，击败她即可救出。
因此需要在蜂袭村地图内的某一处，放置「作为敌人出现」「击败后变为救出」这两个事件。
详情请以蜂袭村(000,003)：「转生角色配置」、同一地图(002,003)：「EV0009_蜂蒂娜」、
同一地图(002,004)：「EV0032」为例。
※该事件的设定略为复杂。
　即使不设定，也只是变得无法救出，不影响游戏进程。
```

- MAP0933：[古代图书馆](./150.md) 的隐藏房间

```
用のぞみの鏡选择追加角色时需要编辑。
即使不设定，也只是变得无法选择，不影响游戏进程。
换装(030,017) 08 页
　选择变身目标角色的处理需要编辑。
　第 101 行附近的「◆变量操作：[1420] 代入, x」中的 x，改为与追加角色 ID 相同的数值。
　第 111 行附近的「◆条件分支：变量[1420] 大于 x」中的 x，改为与追加角色 ID 相同的数值。
角色语音分配(031,017) 02 页
　仿照现有设定，设定追加角色的语音。
```
