## 枪械

### 解说

|  | 蓄力速度 | 伤害修正 | HIT | 射程 | CH | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 射击攻击 | 1 | 100% | 1 | 前15 | 0% |  |
| 锁定射击 |  | 100% | 1 | 前7宽3 | 0% | 单体攻击、能量槽30～99％时 |
| 锁定射击（锁定状态） |  | 100% | 1 | 前7宽5 | 0% | 单体攻击、无需蓄力 |
| 蓄：装填 |  |  |  |  |  | 对应オーラウェイブ |

使用时消耗子弹。由于要在盾牌部位装备子弹，即便分类上是单手，实际上双手都会被占用。
攻击威力基本上不依赖能量槽与使用者的能力，只与子弹的威力有关。
附魔魔法的效果在装填时生效。

锁定射击命中后会进入锁定状态。
锁定状态中无需蓄力即可发动锁定射击，因此可以连续按键攻击。
此外，击破敌人时若锁定范围内还有其他敌人，会自动锁定。
受到攻击被击飞、或自行移动等情况下，锁定状态会解除。
相当方便，但也存在只能单体攻击、在乱战中偏弱的缺点。

每把枪可使用的子弹种类不同。
大致来说，是物理弹与魔法弹两种之一。
