# 快捷键

> 原文：[ショートカット](https://w.atwiki.jp/ryonarpgb/pages/181.html) ｜ 译自 RyonaRPG 勝手にwiki

自 core149 起实装了快捷键系统

把[道具](./161.md)登录到快捷键后，随时都能使用
此外，还能切换装备品和魔法

![](https://i.imgur.com/1tdv8gu.png)

### 快捷键的登录

![](https://i.imgur.com/yGyy1UL.png)

从特殊菜单的「快捷键登录」可以登录[道具](./161.md)
可登录使用型[道具](./161.md)、装备品、魔法
最多可设置 10 个

### 快捷键的使用

![](https://i.imgur.com/5fGnvqy.png)

长按取消键即可打开快捷键

按住方向键的同时按确定键，就会使用该方向上登录的[道具](./161.md)
不按方向键时，使用中央的[道具](./161.md)
按下 Shift 键可以切换快捷键菜单的表与里

习惯之后选择起来会很轻松

> Tips
> 装备中的魔法虽然持有数显示为「0」，但可以使用
> 使用后可以解除装备中的魔法
> 想节约 MP 时很方便

### 快捷键登录示例

表

|  | 喜欢的武器 |  |
| --- | --- | --- |
| キャットナインテール | ポーション | モーニングスター |
|  | チェーンフレイル |  |

里

|  | フレイムセイバー |  |
| --- | --- | --- |
| ポーチ | エーテル | セイントセイバー |
|  | メイジ・アーマー |  |

表菜单用于切换武器与回复 HP
里菜单用于切换魔法与回复 MP
两者合为一套组合
此外，登录ポーチ后，就能使用鎮静剤、黒い鉱石、糸巻き等
