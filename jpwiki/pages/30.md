### 开关

1201～1300

```
通用开关。
只要按特定步骤操作，就能在各张地图里自由使用的开关。
详见地图事件中的「临时开关」。
```

### 变量

0001～0005
0189
5001～5100

```
通用变量。
基本上可以自由使用，但其他事件也会相当频繁地用到，要注意被抢占。
反过来说，预定要比较频繁使用的变量，不要用这些，而是另外新准备一个更稳妥。
5001 以后推荐使用后文所述的通用编号。
```

0901～0905

```
通用编号。
用于「变量～的编号的变量」这一处理。
以前这类处理也用 0001～0005，所以一旦处理撞车，就可能引发非常严重的 bug（例如 0006：主人公被改写等）。
这是为了减少 bug、把集中在 0001～0005 的处理分散开而准备的变量。
```

0906～0908

```
随机数。
用于随机分成 n 种分支、或进行成败判定的变量。
这也是与上文一样，为了从 0001～0005 分散出来而准备的。
```

0509

```
本来用途是给「根据胸围大小判断装备能否使用」的事件准备的变量，
但该事件只在打开菜单时被调用，所以可以像通用变量一样使用。
不过当然不能跨菜单使用，其他事件里也还算常用，需要注意。
```

0610～0614

```
计算用变量。
用于计算中途式子等的变量。
0609 也起了同样的名字，但它在好几个事件里被用作循环条件，还是别用为妙。
```

### 地图事件

添加新地图时，要把地图名追加到公共事件0310：地名取得。

若写着「地图开始时」，例如
要把地图事件放在玩家接触不到的位置，将事件开始条件设为「自动开始」，
并在必要处理结束后执行「事件的临时消除」。

#### 临时开关

```
在地图开始时，把想使用的变量编号的数值代入变量[0891：地图用变量]（推荐 6001 以后），
再调用[公共事件0506：临时开关]，就能在这张地图内自由使用开关 1201～1300。
这些开关会用变量 0891：地图用变量所指定的变量起的 5 个（若指定变量 6001，则用变量编号 6001～6005）
来保存 ON/OFF 状态，下次进入同一张地图时会自动重现。
不过开关 1220/1240/1260/1280/1300 不会被保存，每次都会被清除。
也就是说，这是为了在各种地图里重复使用这些开关的系统，该怎么说呢
另外，向[变量0891：地图用变量]代入 0 的话，就完全不会保存。
```

### 战斗地图

由于会用于攻击处理，基本上要把所有事件的第 1 页空出来。
敌人事件要写好状态调用等初始设定，
不想让玩家角色攻击的事件（例如能对话的人物）要打开开关 0016：无法殴打。
另外，事件受到攻击时的事件也可以在这里指定。
只有特定武器才能破坏的物体在迷宫里很常见，
也许还能做出「坐矿车时改变切换点」这类事件。

在 RyonaRPG 中，必须在地图事件的特定 ID 上放置预先规定好的事件。
上表是历来先驱者们惯用的放置位置。其中以红框标出的是必需的，若没有放置、或放了别的事件，可能会产生某种问题。
这部分很麻烦，所以不太明白的话，先整张地图复制过来再改会比较稳妥。

变量0538：责弄倾向
变量0539：责弄强度

```
在地图开始时指定，就能决定在这张地图内战斗不能时、被捕获中要施以怎样的责弄。
倾向里要填入
	优先部位（0:无　1:B　2:V　3:A　4:N　5:U） * 100 + 概率（0～99）%
例如代入 350 时，
	B：10%　V：10%　A：10 + 50%　N：10%　U：10%
就会按这样的比例执行责弄。
强度为 0～15，单纯表示责弄实际执行的频率，以及其强度程度。

之所以选在地图开始时，是因为时机上比较好懂，但总之只要在游戏结束前决定好就行，
所以也可以改成用「最后攻击的怪物」或「给予最后一击的怪物」来决定。
```
