## 格斗

### 解说

|  | 蓄力速度 | 伤害修正 | HIT | 射程 | CH | 备注 |

| 普通攻击 | 5 | 40-80% | 2-3 | 前方1 | 6% |  |

| 蓄力2：気功弾 | - |  | 1 | 前方5 |  | 武器Lv6以上、圣属性 |

```
普通攻击	机枪刺拳	旋風脚
□□□		□□□			■■■●		☆：使用者
□☆■		□☆■			■☆■●		■：攻击范围
□□□		□□□			■■■●
```

普通攻击的HIT数虽多，但射程短，不好用。
当前版本中，即使没有 功夫鞋，蓄力攻击也会自动变为 旋風脚。

装备 功夫鞋 后攻击范围会增加。
与 皆杀 并用时范围不规则，需要注意（前方4、后方2、宽5）。
只要能使用 旋風脚，就能错开轴线攻击，战斗会稳定下来。
不过武器等级提升后，蓄力阶段容易改变攻击方式，需要注意。
