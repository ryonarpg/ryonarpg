## 关于本汉化

- **翻译范围**：原 wiki 全部游戏相关页面（atwiki 的系统页、旧版本快照、模板页已排除）。
- **术语处理**：人名、地名、系统术语、道具/装备/技能名统一按当前汉化版术语表；[道具 ID 表](/jpwiki/pages/161.md)保留日文原名用于对照。
- **未完成的页**：顶部会显示「本页尚未汉化」，正文保留日文原文，可点「原文」跳转。
- **更新方式**：见 [汉化说明](/jpwiki/about.md)，工具在仓库 `tools/wiki/`。
